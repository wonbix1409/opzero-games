# Operation Zero — игры

Мини-игры для Telegram-бота [@OpZeroHorrorBot](https://t.me/OpZeroHorrorBot) по сериалам канала Operation Zero.

- `index.html` — меню игр (открывается из бота по `?startapp=hub`).
- `nikapli/` — «Ни капли: Правила», глава 1 «Ночь без воды».
- `elektrichka/` — «Последняя электричка 23:59», глава 2 (из бота: `t.me/OpZeroHorrorBot/nikapli?startapp=elektrichka`).

Сайт публикуется через GitHub Pages из ветки `main`.
